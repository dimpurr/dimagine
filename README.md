# dimagine

An agent-native reference image library — Eagle, but every image is a file your agents can read and write.

> Status: pre-alpha, not usable yet. CLI: `dimagine` (short alias `dimg`). License: MIT.

- **Files are the source of truth**: original images plus a sidecar metadata file each; the database is a rebuildable index.
- **CLI first**: built for agents to query, tag and organise in bulk; a minimal web UI comes after.

See [docs/VISION.md](docs/VISION.md) for what this is and is not, and [docs/INDEX.md](docs/INDEX.md) for where each kind of documentation lives.

The name was first used in 2019 for a one-day prototype; that code is kept at tag `v0-2019`.
